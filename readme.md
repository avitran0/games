# Games

## Build requirements

- **Debian 13+:** `libsdl3-dev pkg-config`
- **Ubuntu 26.04+:** `libsdl3-dev pkg-config`
- **Fedora:** `SDL3-devel pkgconf-pkg-config`
- **Arch Linux:** `sdl3 pkgconf`

## Game metadata

```toml
[package.metadata.game]
title = "Title"
description = "Fitting description"
author = "Author"
players = 1
# around 96x64 should be fine
cover = "assets/cover.pxs"
logo = "assets/logo.pxs"
```
