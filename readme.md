# Games

## Requirements

- **Fedora:** `SDL3-devel`

## On Rocknix

1. Enable SSH (default password is `rocknix`)
2. Install Rust, using [rustup](https://rustup.rs)
3. Install Entware (`installentware`)
4. Install git and a c compiler: `opkg install gcc git git-http patchelf`
5. Clone the repository somewhere on device
6. Run `./package.py`
